# Portal Lab — Лаборатория нестабильных порталов

Мини-игра для тестового задания MOX «AI-first Developer 2.0». Смотритель лаборатории управляет магическими порталами: энергией, гномами, ассистентами и риском.

**Живая ссылка:** https://ionshieldquad.github.io/portal-generator/

## За 1 минуту

1. Откройте ссылку — сразу виден список порталов, сверху общий резерв энергии и кнопка «Следующий ход».
2. Выберите действие у портала (оно подсветится и покажет превью): отправить гномов, стабилизировать, настроить коэффициент.
3. Нажмите «Следующий ход» — действия применятся, порталы потратят энергию, гномы принесут очки.
4. Держите порталы открытыми: следите за стабильностью, риском и временем до схлопывания.

Встроенный **AI Worklog** и чек-лист проверки — во вкладке **«О программе»**; правила и формулы — во вкладке **«Обучение»**.

## Запуск

ES-модули не работают через `file://`, поэтому нужен статический сервер (порт — любой свободный):

```bash
python -m http.server 8900
# затем откройте http://localhost:8900

# или
npx serve -l 8900
```

Можно задать сид для воспроизводимости: `http://localhost:8900/?seed=7`

## Тесты

```bash
npm test
```

53 теста через `node --test` по чистым модулям `src/domain/` и стору. Зависимостей нет.

## Управление

- **Приток энергии** (слайдер) — бесплатно, не тратит ход. Превью показывает и портал, и резерв лаборатории.
- **Гномы** — отправка/вывод пипсами; травмы возможны только при переходе через перегруженный портал.
- **Коэффициент Мерлина** — держите у оптимума; он дрейфует каждый ход, настройка может дать сбой.
- **Одно действие на портал за ход**: выберите, затем «Следующий ход».

## Стек

Ванильный JavaScript, ES-модули; без бэкенда и без шага сборки. Хостинг — GitHub Pages. Canvas для анимации портала в карточке, SVG для иконок в списке. Тесты — встроенный `node --test`.

## Структура

```
src/
  domain/        чистая логика (без DOM и localStorage)
    constants.js   все настраиваемые параметры
    util.js        clamp и округление
    rng.js         детерминированный PRNG (mulberry32)
    portal.js      портал: сущность, механика, предикаты
    game.js        состояние мира, селекторы, инварианты
    log.js         единый журнал событий
    actions.js     реестр действий (ActionId + canApply/applyAction)
    sim.js         разрешение хода
    spawn.js       появление порталов
    seed.js        стартовая игра
  storage.js     сохранение в localStorage
  store.js       состояние, поэтапные действия, превью, пресеты, автовоспроизведение
  ui/
    visual.js      портал → визуальное состояние (чистая функция)
    portalShape.js общая геометрия дрожания и молний
    components.js  виалы, шкалы, пипсы, слайдер, SVG-образ портала
    portalCanvas.js анимированный портал для карточки
    hud.js  portals.js  portalDetail.js  log.js  summary.js
    tutorial.js  about.js  worklog.js
    render.js      сборка экранов и обработка событий
    styles.css
  main.js        точка входа
tests/           53 автотеста (node --test)
```

## Хостинг

Статический сайт без бэкенда. GitHub Pages: Settings → Pages → Deploy from a branch → корень. Секреты и токены в коде не хранятся.
